# handoff

Save and resume in-progress, uncommitted work — across sessions, worktrees, or a
different agent entirely. Handoff documents live in the target project's own
`.agent/handoffs/`, not inside this plugin.

## Skills

| Skill | Use when |
| --- | --- |
| [handoff](skills/handoff/SKILL.md) | Pausing or handing off before stopping |
| [resume](skills/resume/SKILL.md) | Starting a session on a project that has prior handoffs |
