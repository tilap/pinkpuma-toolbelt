- **Next.js app structure.** If the `nextjs-app-structure` skill is available, follow it only in a Next.js App Router package (`next` in that package's `package.json`) before adding or moving a file. Routes live in `src/app/`; a component used by a single route lives in that route's `_components/` (for example `src/app/page123/_components/`); shared presentation-only components live in `src/components/ui/`; other shared components live in `src/components/`; configuration lives in `src/config/`; environment variables are read only in `src/env.ts`.
