# git-workflow

Conventions and workflow skills for everyday git work — not a wrapper around git
commands themselves, just the judgment layer on top: what a good commit message says,
what a branch should be called, what a PR description needs, what belongs in a
changelog. See [`CONVENTIONS.md`](CONVENTIONS.md) for the rules every skill here shares.

## Skills

| Skill | Use when |
| --- | --- |
| [commit](skills/commit/SKILL.md) | Committing changes |
| [branch-name](skills/branch-name/SKILL.md) | Starting a new branch |
| [pr-description](skills/pr-description/SKILL.md) | Opening a pull request |
| [changelog](skills/changelog/SKILL.md) | Updating `CHANGELOG.md` or cutting a release |
